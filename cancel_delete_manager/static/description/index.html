Before you install

Enterprise needed?
No. It runs on Community and Enterprise with standard apps only.
Who sees the menu?
Every internal user gets the Cancel / Delete Global group on install.
Other cancel apps?
On install it uninstalls these if present: bi_order_cancel_all, dev_picking_cancel, om_mass_confirm_cancel, acc_invoice_payment_cancel_app, bi_inventory_adjustment_cancel_reverse, eq_payslip_cancel, stock_picking_cancel_extended, pos_order_cancel and cpabooks_all_cancel_extend.
