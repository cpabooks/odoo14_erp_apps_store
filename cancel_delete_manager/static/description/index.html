Action reference

Eight actions in one Cancel / Delete menu

Action What it does
01CancelCancels the document, including posted invoices and done transfers.
02Cancel - LinesCancels the lines and keeps the document and its history.
03Cancel - Linked DocsCancels the order together with its deliveries, invoices and payments.
04Reset to DraftBrings the document back to draft so it can be corrected.
05DeleteRemoves the document after a confirmation step.
06Delete - Linked DocsRemoves the document and the records created from it.
07ReverseCreates the reversal or return instead of removing the original.
08Confirm / PostConfirms or posts again from the same menu after a correction.

How it works

Three steps, every time

1
Select the document
Tick it in the list, or open it in the form.
2
Choose the action
Use the Cancel / Delete button in the list or the Action menu in the form.
3
Confirm
Delete and Reverse ask for confirmation. Every action is logged in the chatter.
Behind the button: matched payments are unreconciled before an invoice is reset or cancelled, actions run in the company of the document, and on invoices Cancel - Lines zeroes the amounts while keeping the rows for the audit trail.

FAQ

Questions

Does it need Enterprise?
No. It runs on Odoo 14 Community and Enterprise. All required apps are standard Community apps.
Who can use it?
Every internal user gets the Cancel / Delete Global group on install, so the whole team sees the same menu.
What about my other cancel apps?
On install, this app uninstalls these older cancel apps if they are installed: bi_order_cancel_all, dev_picking_cancel, om_mass_confirm_cancel, acc_invoice_payment_cancel_app, bi_inventory_adjustment_cancel_reverse, eq_payslip_cancel, stock_picking_cancel_extended, pos_order_cancel and cpabooks_all_cancel_extend.
